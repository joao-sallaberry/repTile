# 0002. Local-first SQLite with sync-ready columns

- **Status:** Accepted
- **Date:** 2026-10-05

## Context

Workouts happen in gyms with bad signal, so the app must work fully offline. Cloud sync (Supabase) is wanted, but later.

## Decision

All data lives in SQLite on the device (expo-sqlite + Drizzle ORM, migrations generated by drizzle-kit). Screens read reactively with `useLiveQuery`. Every table already has the columns a last-write-wins sync needs: UUID `id`, `userId`, `createdAt`, `updatedAt`, `deletedAt` (soft delete) and `dirty`.

## Consequences

- No backend needed to use the app; sync can be added without reshaping tables.
- Every query must filter `isNull(deletedAt)`; writes must go through `createdFields()` / `touched()`.
- Migrations that already shipped to a device can't be edited — only new ones added.
